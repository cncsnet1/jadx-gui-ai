# 自动进入工作区测试包

这是本地复测版本，尚未发布到 GitHub Release。包含 `apkfix.2` 的首页拖放与 APK 加载修复，以及当前工作区的 MCP 功能。

- 左侧“首页”改为“开始”，“文件”改为“工作区”，明确入口和工作空间的区别。
- 打开文件后自动进入工作区并显示文件树。中央显示“文件已就绪”、文件名和浏览提示，避免误以为仍在加载。
- 工作区入口不再切换文件树的显示状态，重复点击也不会隐藏文件树。
- 返回开始页时显示当前文件与“返回工作区”；返回后继续显示已打开的源码。
- 关闭最后一个源码标签后显示就绪提示，资源包也可以正常进入工作区。

GUI 测试和代码风格检查通过。使用提供的《度加剪辑.apk.1》验证了首页模拟拖入、自动切换、返回源码、退出专注模式和关闭最后一个标签的流程；另验证了浅色主题、小窗口、仅含资源的 APK 与加载失败后的恢复。测试覆盖 Swing 事件和组件状态，未重新进行 Windows 鼠标跨应用拖放自动化。

解压后运行 `jadx-gui-ai.exe`。此前的 `apkfix.2` 不含本次导航调整。
