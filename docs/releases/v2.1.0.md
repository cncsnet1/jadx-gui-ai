# JADX GUI AI v2.1.0

v2.1.0 是正式版。打开 APK 后自动获得「应用概览 / 接口与通信 / 关键代码」，先判断保护特征与技术栈，再按实际产物深入。基础分析无需配置模型、Python、Node、Frida 或 Ghidra；需要进一步追查时，Agent 沿选定来源读取代码、更新计划并保存证据。

## 按应用的技术栈走对应路线

- Android、uni-app、React Native、Cordova、WebView、Flutter、Unity 路线可以并存；每条路线展示实际来源、覆盖状态和缺少的材料。
- 可读 JS 支持 uni.request、fetch、axios 请求及配置、存储、拦截器和桥接候选。URL、参数、请求头保留原值，并附文件与位置。
- native 库提供 ELF 架构、受限的导入/导出符号与 JNI 线索。Hermes、Dart AOT、managed 与 IL2CPP 产物显示盘点和解码缺口。
- 接口与通信连接业务调用者、请求参数、加密线索、网络配置和实际流量；关键代码可按路线继续查看并打开来源。
- MCP 共享项目新增只读 `get_apk_profile`，提供保护特征、技术栈与分页 native 信息。

## 少一点噪声，保留判断依据

- API 与关键代码优先展示有来源的请求和业务线索，背景候选默认折叠，说明分层原因，可随时恢复。归属未知不等于低风险。
- 应用类优先扫描，并为资源匹配过多时的应用/未知归属字节码保留额外预算；读取受限时保留覆盖缺口与省略计数。
- 同一发现保留有上限的原文预览及来源索引，减少重复材料挤占上下文。阅读优先级不表示漏洞成立或准确率评分。
- 原始 URL、token、参数、私钥候选与流量证据不作模式脱敏，可随项目保存和全部 API 导出。显式 AI 操作会向所选模型发送相关原文；人工备注不自动发送。

## Agent 从证据开始

- 在模型请求前保存本地起点；选择某条线索时，优先沿该来源与已追踪引用继续，缺失环节再定向搜索。
- 可见计划、原生工具调用及结构化 JSON 兼容模式；读取源码、引用、调用关系、API、资源和已保存证据。
- 每次开始/继续最多 10 轮决策、12 次本地读取，保留取消、错误、预算与未知材料的停止原因。
- 明确收到输出截断时扩大额度并重试一次，兼容 DeepSeek 思考模式工具续接。半份结论不会覆盖完整回答，已有证据可以继续使用。
- 补充一句方向即可继续，计划、步骤、证据和资源目录随项目恢复。切换项目或来源失配时防止旧结果混入。

## Burp 与 Windows 首次使用

- Burp 官方 MCP 扩展可通过内置 HTTP+SSE 连接，使用默认本机地址并保存成功配置，无需代理 JAR。
- 支持限定范围的历史流量、来源关联候选、原始流量证据保存及明确确认后创建 Repeater 标签页；发送请求仍在 Burp 中操作。
- Windows 原生启动器修复英语系统区域下的中文安装/输入/输出路径；不需要修改系统区域或另配 Java。原生启动器要求 Windows 10 1903+ / Windows 11。
- 无效插件记录会跳过，损坏插件清单会隔离备份并继续加载可用插件，避免 `getEnabledPluginJars` 中的空路径使整个项目加载失败。

## 开始使用

1. 下载对应系统包，完整解压，启动应用并打开 APK。
2. 先看应用概览中的保护特征、代码可见性和技术路线；直接打开已发现来源。
3. 在接口与通信梳理 API、请求构造与加密线索，按需连接 Burp；关键代码继续查认证、存储、桥接和 native 产物。
4. 需要 AI 时配置自己的模型连接，选中线索再启动任务；保存 `.jadx` 项目以保留报告与调查证据。

## 验证与能力边界

- GUI 回归共 316 项：314 项通过、2 项网络更新测试跳过；覆盖多路线、JS 提取、ELF 边界、降噪恢复、证据保存/继续、Agent 协议、MCP 与界面操作。发布脚本另有 7 项测试。
- 本地真实 APK 回归包含 25,259 类，获得 823 项发现与 523 条 API；单次扫描约 6.9 秒，只代表该样本与本机环境，不是准确率或完整覆盖证明。
- Windows 打包验收覆盖随包运行时、空配置、无系统 Java、中文路径和深浅主题；CI 另外验证损坏插件清单备份。截图使用应用自身 Swing 组件及本地样本，不代表目标应用结论。
- 六个平台归档校验 JAR、运行时架构、权限、文档与 SHA-256。Windows x64、macOS x64 / ARM64、Linux x64 / ARM64 内置 Temurin 21；portable 需自备 64 位 Java 17+。
- macOS / Linux 包尚未完成对应系统实机回归；Windows EXE、macOS 应用未签名，macOS 未公证。真实 Burp 扩展与设备抓包端到端联调、真实模型质量评测仍待完成。
- 本版没有自动脱壳、Hermes / Dart AOT / C# / IL2CPP 解码或 native 函数体反编译。保护特征未命中不等于无壳。未集成 FlowDroid、LibScout、TruffleHog 引擎；受限静态关联不能当作完整数据流、运行时可达性或漏洞证明。

发布附件包含六个系统包、`SHA256SUMS.txt`、`release-manifest.json` 与 `RELEASE-NOTES.md`，清单记录构建提交和各包摘要。

## English summary

Stable v2.1.0 adds a three-view APK workbench, coexisting framework routes, source-based API prioritization with recoverable background candidates, original-value evidence, resumable local Agent tasks, Burp HTTP+SSE integration, and Windows Unicode/plugin-registry recovery. Basic local analysis needs no model or additional analysis runtime. AI needs your own model connection; external tools need their own setup. Automatic unpacking and Hermes / Dart AOT / IL2CPP decoding are not implemented. Real Burp end-to-end and native macOS/Linux validation remain pending.
