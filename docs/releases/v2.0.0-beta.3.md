# JADX GUI AI v2.0.0-beta.3

这次预发布修复 Windows 首页拖入 APK 后没有响应、加载过程中空白等问题，明确“开始 → 加载 → 工作区”的流程，并新增双向 MCP。

## 文件打开与工作区

- 首页文字、源码编辑器等子控件都能接收文件拖放，保留文本复制粘贴；拖入时高亮，松开后显示加载状态。
- 加载成功后自动进入工作区并显示文件树。尚未打开源码时显示“文件已就绪”、文件名和下一步操作。
- 左侧“文件”改为“工作区”，重复点击不会隐藏文件树；返回开始页时提供“返回工作区”，继续阅读之前的源码。
- 关闭最后一个源码标签后显示就绪提示；仅含资源的 APK 也能打开。加载失败显示错误入口，支持重新打开其他文件。
- 大型资源树在后台构建，并改进目录查找；连续打开文件时串行处理，避免加载期间相互关闭反编译器。
- 修复 APK 内嵌压缩文件读取时，Java 输入插件临时目录不存在导致的异常。

## 双向 MCP

- 工具菜单新增 MCP 连接中心。外部客户端可通过本机 Streamable HTTP 查询当前项目、类、源码、方法和引用。
- 项目共享默认关闭，仅绑定本机回环地址，使用临时令牌；切换或关闭项目会撤销共享。
- 支持主动连接 stdio / HTTP MCP 服务，手动测试工具；内置 AI 可在用户启用后选择工具，每次执行需要确认。
- 工具对话有轮次、调用数、时间和返回大小限制。不会自动启动外部服务或安装依赖。
- 支持范围与配置见 [MCP 使用说明](https://github.com/cncsnet1/jadx-gui-ai/blob/v2.0.0-beta.3/docs/MCP.md)。

## 验证与发布包

- GUI 测试 108 项通过、2 项跳过；Java 反混淆预处理插件 18 项测试及内嵌归档回归测试通过；打包脚本 6 项测试通过。
- Windows 使用约 52 MB 的 APK 样本验证首页模拟拖入、自动进入工作区、源码显示、返回开始页、专注模式及关闭最后一个标签；原始 `.apk.1` 文件无需改名。
- 验证深浅主题、960×640 小窗口、仅含资源的 APK、连续打开及加载失败恢复。拖放测试覆盖 Swing 接收事件，未完成鼠标跨应用拖放的自动化复测。
- 六个平台包附带 SHA-256 和来源提交清单。Windows 包验证运行环境、CLI 与 GUI；macOS / Linux 限于归档、架构、权限与内容校验，未在对应系统实机启动。
- Windows EXE 和 macOS 应用未签名，macOS 未公证；portable 包需自备 64 位 Java 17+。

建议完整解压新目录后运行。配置的 AI 服务与外部 MCP 服务需自行提供；本版本仍为预览版。
