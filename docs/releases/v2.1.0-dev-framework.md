# 2.1.0-dev-framework（本地开发预览）

> 历史开发记录：相关功能已整理进入 [v2.1.0 正式版](v2.1.0.md)。下文保留当时的预览状态与验证范围。

本次构建接续 APK 工作台预览，不是 GitHub 正式发布版。Windows x64 包自带 Java，解压后双击 `jadx-gui-ai.exe`；本地分析无需安装额外环境。

- 线索、源码、URL 查询值、请求头、实际参数和保存的流量证据保留原值，贯穿界面、项目保存及导出。AI 按选中的证据和后续读取内容接收原文。
- 识别 uni-app 后自动读取配置、页面、业务脚本、请求封装、鉴权存储、拦截器和 native 桥接。概览直接给出已找到的来源和可继续的下一步。
- JS 请求支持有依据的字面量拼接和同作用域常量，保留常量声明与请求位置。运行时变量及跨文件绑定保持未知。
- Agent 可分段读取当前项目的 JS、JSON、HTML 等资源，并沿所选源码继续分析；同名资源保留所属 APK 身份。
- 保留读取上限与覆盖缺口，未支持的框架不冒充已完成业务分析。打开、重扫、查看结果不自动调用模型。

旧版已经抹掉的值不能从历史记录恢复，升级后会重新扫描原始输入。自动脱壳、native 反编译和完整 JS 数据流尚未实现。范围及操作见 [APK 工作台](../APK_WORKBENCH.md)。
