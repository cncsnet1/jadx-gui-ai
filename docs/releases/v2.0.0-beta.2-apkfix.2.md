# 首页拖放与 APK 加载测试包

这是本地复测版本，尚未发布到 GitHub Release。继承 `apkfix.1` 的后台构树、加载状态与失败恢复，同时包含当前工作区的 MCP 功能。

- 首页改为明确的文件导入入口：拖放区域、选择文件、打开项目和最近项目。拖入时高亮，离开时恢复，松开后进入加载状态。
- 修复首页说明文字、源码编辑器等 Swing 子控件拦截文件拖放的问题，保留文本复制粘贴与原有传输操作。
- 动态加入的控件和替换的文本传输处理器继续支持文件拖入。
- 修复首次读取 APK 内嵌压缩文件时，Java 输入插件的临时目录尚未创建导致的错误。

验证了文件拖放回调、反馈清理、文本复制粘贴、动态控件和内嵌归档；GUI 测试与代码风格检查通过。深浅主题、960×640 小窗口均完成组件渲染检查。

用户提供的约 52 MB《度加剪辑.apk.1》通过首页文本区的模拟拖入路径加载，未改名；本机单次加载约 10.7 秒，读取 25,258 个类，并抽查一个业务 Activity 的源码显示。该测试覆盖 Swing 接收事件至加载及源码显示，不等同于完整反编译所有类。Windows 原生截图工具超时，未完成鼠标跨应用拖放的自动化复测。

解压后运行此目录中的 `jadx-gui-ai.exe`。此前的 `apkfix.1` 不含本次首页更新。
