# 2.1.0-dev-workbench（本地开发预览）

> 历史开发记录：相关功能已整理进入 [v2.1.0 正式版](v2.1.0.md)。下文保留当时的预览状态与验证范围。

本次构建供体验新版 APK 工作流，不是 GitHub 正式发布版。Windows x64 包自带 Java，解压后双击 `jadx-gui-ai.exe`；本地分析不需要安装额外环境，AI 沿用已有模型连接。

- 主界面改为「应用概览 / 接口与通信 / 关键代码」，AI 从具体线索展开为详情，可随时返回本地结果。
- 本地盘点保护特征、框架产物、DEX / JS / native 分布，给出有来源的下一步入口。
- 提取直接 uni.request、fetch、axios 调用；将接口的调用入口、参数、加密签名、网络出口和实际流量组织为五段。
- 保留常见算法常量与加密 API 摘要，增加受限 ELF 架构、导入导出和 JNI 符号盘点。
- MCP 新增只读 `get_apk_profile`；重扫和恢复报告不自动请求模型，已读接口链路可复用。
- 修复 JS 除法与截断 HTML 导致的漏提取、多 APK 同名来源错配，并为继续 AI 任务增加来源身份校验。

自动脱壳、native 反编译、动态 JNI 绑定和完整 JS 数据流尚未实现。界面中的未知、疑似和覆盖限制保留这些边界。详见 [APK 工作台](../APK_WORKBENCH.md)。
