# JADX GUI AI v2.0.0

v2.0.0 正式版把 APK 分析组织为「应用报告 → API 地图 → 调查记录」。打开文件即可获得本地报告；选择接口可追查调用路径，配置模型后可让 AI 继续读取代码、保留证据与未解问题。基础分析使用内置 JADX，无需额外配置 Python、Node 或 REA。

## 报告优先的工作区

- 加载 APK 后自动执行有预算的本地扫描，不因已配置模型而自动发送源码。首页在项目打开后返回应用报告。
- 报告先展示值得看的线索与调查目标，全部结果、技术详情和人工核查按需展开。
- 统一石墨灰与青绿色界面，保留浅色主题，改进窄窗口布局和大结果列表的响应。

## 内置 API 追查

- 「一键梳理接口」从接口声明或网络请求构造方法向上追查业务调用者。每条连线核对原始字节码中的精确调用目标，保留指令类型、偏移和方法签名。
- 默认最多 4 层、48 个方法和 96 条关系。支持重载方法、循环与共用分支，显示无法继续追查的原因，可查看依据并跳转源码。
- 按需解析常见直线式 Retrofit / OkHttp 构建代码，分别保留多个客户端的基础地址和拦截器；动态配置、辅助方法、注入和分支保持未知。
- API 清单与调用路径随项目保存；JSON 导出升级到 schemaVersion 3，保留 endpoints 与 clientRelations，后者包含 callPath；Markdown 同时保留可读关系与来源。

## 可继续的 AI 调查

- 每轮最多选择 3 条起点、6 次规划和 12 次本地读取；模型使用已有目录标识读取源码、引用、调用关系、API 档案及已保存证据。
- 保存步骤、来源、未解问题、停止原因与上次完整回答。取消或请求失败后保留已读取证据，可继续同一调查。
- 每项目最多 24 条调查，每条最多 96 份证据；恢复时校验输入文件身份和引擎配置，避免旧材料混入其他项目。
- 项目保存采用临时文件与原子替换，改善保存中断时的可靠性。

## MCP 与可靠性

- 共享项目新增 trace_calls 与 inspect_api，后者与界面复用客户端解析和有界调用路径。
- 外部 MCP 新增 rea-static 工具筛选、较大目录发现和会话内结果分页；沿用逐次调用确认，未安装或自动启动 REA。
- 修复未保存项目取消操作、报告缓存校验、敏感 URL 脱敏、列表渲染等边界问题，并加强 ZIP 路径校验。
- 原有源码助手、AI 搜索、多模型连接、人工核查与 Java 反混淆预处理继续保留。

## 开始使用

1. 完整解压新包，打开 APK、DEX、JAR 或 CLASS，等待本地报告。
2. 在 API 地图选择接口声明或请求构造入口，点击「一键梳理接口」。
3. 配置自己的模型连接后，选择报告中的调查目标，或沿线索继续追查。
4. 保存 `.jadx` 项目，或导出报告与 API 清单供后续核对。

静态关系不代表实际执行、外部可达或漏洞成立。反射、native、动态分派、运行时材料与服务端行为仍需额外证据；工具不会自动执行 APK、请求目标接口或验证凭据。REA 原生引擎联调和完整图探索未包含在本次发布中。

## 验证与发布包

- GUI 自动化：180 项通过、2 项跳过；覆盖 API 关系正反例、重载与循环、证据保存恢复、调查取消、MCP 分页和 ZIP 边界。
- Windows 实际界面验证：自动扫描、报告导航、API 追查、依据弹窗、源码跳转、调查继续、保存恢复、卸载，以及深浅主题和窄窗口。
- 真实大 APK 回归覆盖 25,259 类；选定请求构造入口保留 10 个方法与 9 条静态关系，并标出未展开边界。单次性能数据仅代表该样本和本机环境。
- AI 交互回归使用本机模拟服务验证流程，不代表真实模型的识别准确率。
- 六个平台包提供 SHA256SUMS.txt、release-manifest.json 与本说明，校验 JAR 一致性、运行环境架构、权限及文档完整性。
- Windows x64、macOS x64 / ARM64、Linux x64 / ARM64 内置 Eclipse Temurin 21；portable 需自备 64 位 Java 17+。模型与外部 MCP 服务需自行提供。
- Windows 包验证实际启动；macOS / Linux 包进行归档校验，尚未完成对应系统实机回归。Windows EXE 和 macOS 应用未签名，macOS 未公证。
