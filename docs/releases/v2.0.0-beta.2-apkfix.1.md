# Windows APK 加载修复测试包

此版本用于复测 Windows 拖入 APK 后界面空白或无响应的问题，尚未发布到 GitHub Release。包含当前工作区的 MCP 功能。

- 将首次文件树构建移到后台，优化资源目录查找，避免大量同级目录导致界面线程长时间阻塞。
- 加载过程显示进度卡片；初始化失败、内存不足或输入为空时显示失败页面，并提供日志与重新打开入口。
- Windows 拖放回调结束后再打开文件，连续打开请求按加载状态衔接，保留最后一次请求。
- 支持仅含资源的 APK 正常进入工作区。

验证：使用 Windows 包内置运行时，普通 APK、资源 APK、失败后重试、连续打开和两种主题均通过；新增 6 项回归测试，GUI 测试共 105 项（103 通过、2 跳过）。含 3 万个资源目录的合成 APK，单次测量最长界面停顿从约 2.9 秒降到约 0.29 秒。该样例尚不能代替反馈者的原始 APK。

解压后运行 `jadx-gui-ai.exe`。如果原 APK 仍无法加载，请从界面中的“日志”入口获取错误信息，并附上 APK 大小与测试包版本。
