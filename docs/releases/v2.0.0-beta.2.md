# JADX GUI AI v2.0.0-beta.2

这次预发布重新组织了整个分析工作空间，并重做 AI 搜索：从首页打开项目，用命令面板快速找到工具，在源码旁查看回答、追溯引用和保存记录。

## 界面与交互

- 全新首页、左侧导航、统一命令入口和底部状态区，提供石墨灰 / 青绿色的 Jadx Graphite 及 Jadx Light 浅色主题。
- `Ctrl + K`（macOS 为 `⌘ + K`）搜索并执行现有菜单命令，保留原有菜单、快捷键及禁用状态。
- 专注模式临时收起文件导航和代码助手，恢复时保留面板选择与宽度；首页重复打开复用同一标签。
- AI 侧栏将分析、引用源码、调查记录并列展示；上下文选项与结果操作收纳到菜单，紧凑窗口优先保留回答区域。
- 旧配置保留原主题，可以在“文件 → 首选项 → 外观”切换到 Jadx Graphite。

## AI 搜索

- 支持包范围、当前类及内部类范围、临时模型选择、请求批次与目标服务预览。
- 分批返回类名和匹配理由，支持本地筛选及跳转源码；取消或失败后保留已完成批次。
- 严格校验返回类名，丢弃虚构、越界和重复结果；项目卸载及重新搜索会使旧回调失效。
- 搜索使用问题与类名语义线索，不发送方法体，也不等同于源码行为分析。

## Java 反混淆预处理

- 新增可选的本地 Java Deobfuscator 集成，在普通 JAR / CLASS 载入前检测 ZKM、Allatori、Stringer 并选择受支持规则。
- 提供仅检测、手动规则、自定义规则、处理报告、超时限制和输出结构检查；失败回退原输入。
- 外部引擎需自行获取并配置，未随包分发。AFT 产品未明确，不声明支持；不能保证商业混淆器所有版本和组合均能还原。
- 详细配置与边界见包内 `docs/JAVA_DEOBFUSCATION.md`。

## 验证与发布包

- GUI 自动化测试：81 项通过、2 项跳过，包含布局恢复和命令可用性测试。
- Windows 本机模拟服务回归覆盖深浅主题、1360×900 / 960×640 布局、搜索范围、过滤、跳转、取消、错误、分析、保存和首页切换。
- Java 预处理插件 18 项测试通过，包含规则规划、输出校验、失败回退和真实外部引擎测试；自建 Allatori 风格样本验证不代表商业产品全部版本的兼容性。打包脚本 6 项测试通过。
- 六种附件沿用 Temurin 21 锁定运行环境，并提供 SHA-256、来源提交和构建清单。Windows / macOS / Linux 平台包内置运行环境，portable 通用包需要自备 64 位 Java 17+。
- macOS / Linux 验证限于归档、架构、权限与内容完整性，尚未在对应系统实机启动。Windows EXE 与 macOS 应用未签名，macOS 未公证。
- CLI 原有 `TestInput.testClassInput` 依赖仓库缺失的 `samples/HelloWorld.class`；不宣称全仓测试全部通过。

解压完整目录后运行；AI 服务与模型需自行配置。预览图使用演示源码与本机模拟服务，不代表实际模型推理效果。
