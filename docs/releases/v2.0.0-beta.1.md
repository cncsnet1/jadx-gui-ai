# JADX GUI AI v2.0.0-beta.1

这次预发布把 AI 分析接进了源码阅读与证据复核流程：在当前代码旁提问，明确看到发送内容，将有价值的回答整理为可保存的调查线索。

## 新增

- **源码工作台**：方法 / 选区上下文、可选调用者、解释 / 追踪 / 审计 / 命名、可停止的流式响应与源码引用跳转。
- **AI 连接中心**：多云端与本地连接、任务分配、模型列表读取、环境变量密钥、流式响应诊断。
- **上下文预检**：发送前检查源码快照和完整消息，发送复用预览中的同一份快照。
- **调查台**：源码观察、待证假设、开放问题；引用片段核对、人工复核、反证笔记与项目持久化。
- **报告导出**：Markdown / HTML 保留来源、证据快照、模型原文及人工判断。
- **多平台发布包**：Windows x64、macOS Intel / Apple Silicon、Linux x64 / ARM64 内置 Temurin 21，另附不含 Java 的通用包。

## 改进

- 重复保存分析或复核不再产生重复记录。
- 切换项目会取消请求并丢弃过期回调。
- 注释与命名先预览，源码变化后阻止直接应用旧建议。
- 对齐已有 AI 菜单翻译资源，修复 GUI 的多语言一致性检查失败。
- 重写 GitHub 首页与使用手册，界面截图来自演示代码与本地模拟服务。

## 验证与限制

- GUI 测试共 70 项：68 项通过、2 项跳过，其中 AI 相关 44 项通过。
- Windows 已进行打包后的 CLI 与原生 GUI 启动检查，以及本地模拟服务下的分析、配置、调查台与项目保存集成检查。
- macOS / Linux 包已做归档、运行环境架构、权限、启动脚本与内容完整性检查；尚未在对应系统实机启动。
- Windows EXE 与 macOS 应用尚未进行发布者签名，macOS 应用未公证。
- 当前需要兼容 Chat Completions 的接口；不支持结构化线索的模型仍可输出普通文本。
- 当前不包含跨分析调查目标、多模型自动复核或自动动态验证。

根据处理器架构选择对应附件，先解压再运行。平台包无需另装 Java；通用包需要 64 位 Java 17+。AI 服务与模型需自行配置。
