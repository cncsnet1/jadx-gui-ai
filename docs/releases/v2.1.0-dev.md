# v2.1.0-dev · Windows 体验预览

此构建用于验证更省事的首次使用流程，属于开发预览；GitHub Latest 正式版仍为 v2.0.0。

## 这次解决什么

- **Agent 任务工作台。** 快捷目标、自然语言任务、可更新的计划、原生函数调用及自动兼容回退；读错目标后可以重新规划。补充方向后沿用证据继续，计划与方向随工程保存，无需新增 Agent 环境。见 [Agent 工作台说明](../AGENT_WORKSPACE.md)。

- **Burp 直接连接。** 在 Burp 的 Extensions → BApp Store 安装 MCP Server，在 MCP 页勾选 Enabled；回到 JADX 的「应用调查 → API 地图 → 实际流量」，点击「连接 Burp」。默认连接本机 9876 端口，成功后保存配置，无需代理 JAR、Java 路径和启动参数。
- **失败时知道下一步。** 连接失败后直接提供官方扩展安装页与连接地址入口；改过端口时才需要调整地址。原有 stdio 连接仍可使用。
- **插件清单自动恢复。** 跳过缺失或无效的插件 JAR 记录；JSON 损坏时先保存完整 `.bak` 备份，再继续加载内置与 dropins 插件。损坏清单中的外部插件需重新安装，备份位置会写入日志。
- **中文目录直接打开。** Windows 完整包改用进程级 UTF-8 原生启动器，修复英文系统区域下中文安装路径导致 Java 启动失败的问题，无需修改系统区域。适用于 Windows 10 1903+ / Windows 11。
- **从 API 到实际流量。** 读取已捕获的 HTTP 历史，核对候选源码，保存证据摘要，或将完整请求放入 Burp Repeater。转交本身不会向目标发送请求。

## 打开方式

完整解压 Windows x64 包后，双击 `jadx-gui-ai.exe`。包内附带 Java 21，APK 本地报告与 API 地图无需另装 JDK、Python 或 Node，也不要求配置模型。联网 AI 解释仍需用户自己的模型服务配置。

## 验证与边界

- GUI 单元及集成测试：215 通过、2 跳过；插件清单测试：5 通过；打包脚本测试：7 通过。
- 内置 Java 21 的 Windows 包在中文及空格目录、中文配置与缓存目录下验证，清空 `JAVA_HOME` 并从 PATH 移除 Java 后仍可运行；异常插件清单也能备份恢复。
- Windows Swing 验证覆盖：空 MCP 配置、连接失败提示、重试与配置复用、流量读取、证据保存与恢复、源码跳转、Repeater 转交、取消与项目卸载，以及中英文和深浅色布局。
- Agent 验证覆盖原生工具、错误后的重新规划、补充方向、工程磁盘恢复、取消保留和深浅色任务界面；模型推理质量仍需实际模型与 APK 验证。
- 协议测试覆盖直接 HTTP+SSE、同源消息端点、超时、取消、异常报文及大小限制。
- Burp 使用本机协议样本验证，尚未完成真实扩展和手机抓包的完整联调。Burp、官方扩展及设备抓包环境仍需准备；静态关联不等于漏洞成立。

详情见 [Burp 联动说明](../BURP_WORKFLOW.md)。
